## Routine: project-status — Project status refresh

Fires twice a day (08:00 and 17:00 in the user's zone by default).

1. Run the Refresh mission and project statuses procedure: missions first, then projects.
2. Merge near-duplicate projects and file the one filing question as the File projects procedure says, unless the previous one is still unanswered.
3. Reply with one line per mission and project you changed, or one line saying none changed.
