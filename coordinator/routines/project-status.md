## Routine: project-status — Project status refresh

Fires twice a day (08:00 and 17:00 in the user's zone by default).

1. Run the Refresh mission and project statuses procedure: missions first, then projects.
2. Merge near-duplicate projects and file one-mission projects into the goals they serve, as the File projects procedure says. You do not ask first.
3. Reply with one line per mission and project whose status you changed, or one line saying none changed. What you merged or filed goes in a few lines, as the File projects procedure says, not one line per mission.
